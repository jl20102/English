# Midsummer Night's Dream — Puck's Phone Home Screen

## Overview
Creative assessment project: a mock smartphone home screen built as an Expo (React Native) mobile app, simulating the phone of **Puck (Robin Goodfellow)** from Shakespeare's *A Midsummer Night's Dream*. Reflects his mischievous, fairy-trickster personality through themed apps, content, and a mystical-forest aesthetic.

## Stack
- **Framework:** Expo SDK 54 + Expo Router (file-based routing)
- **UI Libs:** expo-blur, expo-linear-gradient, @expo/vector-icons
- **Fonts:** Playfair Display (display serif for Shakespearean quotes), Outfit (sans body)
- **No backend** — pure frontend creative mock

## Screens
| Route | Description |
|---|---|
| `/` | Home — wallpaper, status bar, large time/date, quote widget, 4×2 app grid, glass dock |
| `/spotify` | "Midsummer Mischief" playlist — album art, controls, 5 character-themed songs |
| `/dating` | "Spark" dating app — Puck's profile + Matches tab with Titania & Helena |
| `/messages` | Texts with Oberon (full conversation about the love-juice mishap) |
| `/notes` | Puck's "Tonight's Mischief List" checklist with toggleable tasks |

## Required Deliverables (per assessment)
✅ **Spotify App** — 5 songs (3+ required): *I Put a Spell on You*, *Sympathy for the Devil*, *Midnight City*, *Bad Guy*, *A Little Less Conversation* — each with a "why-Puck-loves-it" note  
✅ **Dating App Profile** — Robin Goodfellow's bio (5 sentences in trickster voice), interests, "what he's looking for"  
✅ **2 Potential Matches** — Titania (Fairy Queen, "Royally Compatible") + Helena (mortal, "Chaotic Pairing")  
✅ **Character reflection** — apps & content tie to Puck's role: serving Oberon, mischief, love-potion confusion, breaking the fourth wall

## Design System
- **Palette:** Midnight indigo `#05050A`, lavender `#B388FF`, gold `#FFC107`, emerald `#00E676`, rose `#FF4081`
- **Vibe:** "Apple designed for fairies" — glassmorphic widgets, gradient app icons, soft glow shadows, mystical forest wallpaper
